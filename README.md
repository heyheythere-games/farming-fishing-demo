# Farming & Fishing System: playable demo

Play the demo of **Farming & Fishing System**, an Unreal Engine plugin by heyheythere, before you buy it.

## Download

- [Latest release](../../releases/latest): `FarmingDemo-Win64.zip`, for Windows 10 or 11, 64-bit.
- Unzip it anywhere and run `FarmingDemo.exe`.
- The demo shows the plugin's version 1.1.0, the same one sold on Fab.

## Controls

| Action | Keyboard and mouse | Gamepad |
|---|---|---|
| Move | W A S D | Left stick |
| Look | Mouse | Right stick |
| Jump | Space | A |
| Tool | 1 to 6, wheel | LB, RB |
| Use, cast, reel | Left click | RT |
| Next seed | E | X |
| Sleep, by the bed | Z |  |
| Wait an hour, next season | T, F3 |  |
| Save, load | F5, F9 |  |
